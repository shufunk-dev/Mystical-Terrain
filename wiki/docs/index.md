## 📦 Compatibility & Runtime Matrix

Mystical Terrain (Community Patch Edition) modernizes legacy codebase conventions to support modern Fabric runtime standards.

| Component | Target Version | Status | Notes |
|---|---|---|---|
| **Minecraft** | `1.21.2` – `1.21.11` | <span class="badge-cyan">Supported</span> | Modern item component & tag syntax |
| **Fabric Loader** | `>= 0.16.0` | <span class="badge-purple">Required</span> | Tested up to `0.19.3` |
| **Fabric API** | `0.141.6+1.21.11` | <span class="badge-purple">Required</span> | Dedicated server mixin isolation |
| **GeckoLib** | `>= 5.4.5` | <span class="badge-cyan">Required</span> | Powers animated colossi & dragon renders |
| **TerraBlender** | Compatible | <span class="badge-purple">Optional</span> | Surface rules & biome region injection |
| **Java Runtime** | `Java 21` (LTS) | <span class="badge-cyan">Required</span> | Pattern matching & virtual threads |

::: tip Sister Mod Integration
Mystical Terrain is paired with **[ShuDynamics](https://shudynamics.shufunk.net)**. While Mystical Terrain expands the natural topography and mystical fauna, ShuDynamics provides industrial automation, energy conveyance, and mechanical processing.
:::
